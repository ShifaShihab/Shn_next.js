# 🍽️ HungryHun

Turn your pantry staples into delicious recipes!


**HungryHun** is a fun and simple recipe suggestion web app that helps you cook using whatever ingredients you already have at home.  
Perfect for students, beginner cooks, and late-night food experiments!

![Screenshot 2025-06-26 090844](https://github.com/user-attachments/assets/ac3cfe2b-1282-47bc-8372-6a80922f97d0)



---

## 🔍 Features

- 📝 Add pantry ingredients like `rice`, `eggs`, or `bread`
- 🔍 Suggests matching recipes from a curated list
- 🍳 Easy-to-follow cooking instructions
- 🎬 Links to YouTube videos for step-by-step guidance
- 😌 Friendly empty-state messages if no recipes are found
- ✨ Beautiful handwritten-style UI with soft gradients
